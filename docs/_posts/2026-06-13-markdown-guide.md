# 마크다운 렌더링 데모

본문 영역에서 마크다운 요소들이 어떻게 스타일링되는지 확인하세요.

## 1. 코드 블록
개발 블로그 필수 요소인 코드 블록입니다:
```javascript
const greeting = "Hello, World!";
console.log(greeting);
```

인라인 코드 표시 예시: `const isLocal = true;` 처럼 강조할 수 있습니다.
