노란귤 블로그에 오신 것을 환영합니다!

2026-06-14 • 2 min read

안녕하세요! 노란귤의 개인 블로그에 오신 것을 진심으로 환영합니다. 이 블로그는 정적 파일만을 사용하여 빠르고 직관적인 독서 환경을 제공하는 개발자용 블로그 공간입니다.

1. 블로그 디자인 컨셉

요청된 가이드라인에 맞추어 제작된 이번 테마의 주요 컨셉은 다음과 같습니다.

  • 화이트 배경: 텍스트 가독성을 가장 우선순위에 두고 깔끔하고 편안한 백그라운드를 제공합니다.
  • 골드 포인트: 주조색 #ffce00을 활용해 브랜딩 가치와 모던한 액센트를 부여합니다.
  • 3단 구조 레이아웃: 정보 구조를 한눈에 볼 수 있도록 균형감 있는 배치를 구현했습니다.

2. 주요 기능 및 레이아웃 구성

효율적인 웹 서핑을 위해 블로그 곳곳에 편리한 장치를 구성해 두었습니다.

좌측 사이드바에서는 닉네임과 함께 소개글, 그리고 카테고리가 항상 유지되며 우측 목차(TOC)를 통해 긴 글에서도 길을 잃지 않고 탐색할 수 있습니다.

3. 게시글 작성 에디터 지원

아래 섹션에 준비된 에디터 폼을 통해 마크다운 문법으로 새로운 게시글 초안을 바로 작성할 수 있습니다.

// 노란귤 블로그 개발 정보
const blogInfo = {
    owner: "노란귤",
    primaryColor: "#ffce00",
    layout: "3-Column Grid"
};
console.log("Welcome to Yellow Tangerine Blog!");
